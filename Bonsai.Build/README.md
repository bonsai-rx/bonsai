## About

`Bonsai.Build` provides the compiler infrastructure used to build C# extensions for the [Bonsai visual reactive programming language](https://bonsai-rx.org).

## How to Use

To use `Bonsai.Build`, refer to the [official Bonsai install guide](https://bonsai-rx.org/docs/articles/installation.html).

## Additional Documentation

For additional documentation and examples, refer to the [official Bonsai documentation](https://bonsai-rx.org/docs/).
